# D006 이사 지킴이 v0.3 판정

**결론: 문제는 그대로 두고(계약금 송금 전 견적 빈칸 → 이삿날 "이건 추가요"), 업체를 정하지 않은 상태에서 조건 한 문장으로 맞춤 홈을 만들고, 에이전트 10명(LLM 3·규칙 7)이 일하는 장면으로 점검 과정을 보여 준다. 단, 장면보다 검증기 수리와 견적·문의·답변·비교 흐름을 먼저 만든다.**

토론 생략 사유: 두 위원의 판정이 갈린 K2·K3·K5·K6·K7·K11은 서로 반대 방향이 아니라 보완 조건이 달랐다(같은 방향, 다른 조건). 의장이 두 조건의 합집합을 채택했다.

## 확정 설계
- **에이전트**(Sonnet안): 지휘관(규칙, 끌 수 없음) / 채비팀 조건 해석관(LLM ax4)·짐 점검표관·서류 안내관 / 견적팀 문서 읽기관(LLM ax4)·견적 대조관·업체 고르기 도우미 / 안심팀 문의 작성관·답변 점검관(LLM qwen3)·계약 점검관. 표현은 "10개 작업 역할 중 3개가 LLM"(Astra).
- **토글**: 서버 GPU 대기열 1개 + `req.signal` 전파·취소, 끈 역할 결과는 '이전 결과 · 현재 꺼짐'으로 보존, 상류가 꺼져도 유효한 직접 입력이 있으면 하류 실행. **수동 입력·수동 반영도 같은 검증기를 통과해야 한다**(Argon #5).
- **숫자**: 근거 없는 추정 금지(㎥·톤수·인원·가격·적재율). 원문 금액·건수·검증된 입력 비율은 허용. 차량·인원은 "업체 확인 필요" 질문으로.
- **업체 고르기**: 업체별 문의·답변을 최종 선택 전에 허용, 공통 점검 항목을 고정 행으로 한 비교표(입력 순, 자동 강조·정렬 없음), 관악구 허가 목록은 정적 JSON(전화·좌표 제거, `구분`·`영업상태명` 확인 행만 후보), 표시는 "동일 상호 기록 있음 · 동일 업체 미확인 — 허가증 사본 대조". 가상 견적을 실존 업체에 연결하지 않는다.
- **AI 기능**: AI(F1 한 문장→조건, F3 다중 견적 읽기, F7 답변 점검(후보별), F8 계약서 읽기) / 규칙(대조·질문·비교·서류·계약금 비율) / 표현(장면·그래프)으로 나눠 제시. 이삿날 체크는 보조 안내로만.
- **장면**: 새 SVG, 600줄 이하 — 출발 집·트럭(멈춤선·질문 게시판)·도착 집 3개 미니 SVG를 CSS grid로(모바일 자동 세로), 도구는 lucide 아이콘, 10명 상태는 장면 아래 `AgentStrip` + 팀 대표 작업대, 동기화는 `cardsOf(state)` 단일 파생 + `revealedCount` 커서(이벤트 큐 없음). 옷 색: 채비팀 `#2F6DB5`, 견적팀 `#B84A18`, 안심팀 `#2E7D4F` + 팀 기호 배지.
- **디자인**: TRITON 셸 + 팔레트 A(사용자 선택) hex 그대로.

## 시연
라이브 중 모델 교대 0회(8GB GPU에 두 모델 동시 상주 불가 — Argon 추정). 교대가 필요한 단계는 처음부터 "사전 실행 결과 재생"으로 표시. Astra 수정 대본: 모호한 문구 → 한 문장 조건 → 상자 멈춤·질문·원문 → "당일 보고 결정"은 미확인 유지 vs 명확한 답 → A/B 공통 항목 비교 → 토글·입력 변경 시 '갱신 필요' → 측정 결과·한계.

## 기획서 원칙 (Astra)
