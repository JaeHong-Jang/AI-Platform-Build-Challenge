# D007 판정

**결론: 웹은 '에이전트가 실제로 일한 결과'를 보이게 하고(작업 보고·근거 장부·근거 그래프), 기획서는 실측 정확도와 정직한 한계를 앞세운다.**

## 웹 (구현됨)
- 에이전트 10개 작업 역할이 지휘관 순서대로 작동→완료, 각자 산출물 한 줄과 근거·출처(`lib/pipeline.ts`). '대기만 뜸' 해소.
- 색: 안심 네이비(사용자 선택, `runs/out/b009-palette.sonnet.md` A안 hex 그대로). TRITON 갈색 폐기.
- 견적 받을 업체 찾기(관악구 허가 공공데이터 27곳, 순위·추천 없음), 근거 장부(모델 출력→검증→승인), 근거 그래프(force 네트워크 + 4열 사슬), 모바일 하단 탭바, 행 내 근거 펼침, 문구·범례 정리.
- 속도: 모델 미리 올리기(`/api/warmup`). 답변 점검 12.4 → 4.9초. 카드 선제공은 더 느려서 폐기.
- 정확도(`web/eval/`): 튜닝셋(Sonnet 작성, 실패를 고친 뒤 재측정) 견적 오반영 5→0·답변 40→1. **홀드아웃(Sol 작성, 코드 수정 없음)** 견적 오반영 7→4·재현율 86→92%·지어낸 값 4→0, 답변 오반영 11→4. 검증기는 줄이지만 0은 아니다 — 지시어·조건부 표현이 남은 과제.
