# D004 이사 지킴이 웹 구현 판정

**결론: 모바일 웹 프로토타입(`web/`)을 채택하고, D003에서 P1이던 '업체 답변 점검'을 에이전트로 프로토타입에 포함한다.** 사진·견적서 읽기는 AI 호출 2번(동시), 대조·문구는 규칙과 문장 틀, 에이전트는 업체 답변 점검 한 곳에만 둔다(Sol 분석). Argon은 TOP 5 중 #1·#3·#5 수정을 조건으로 찬성했고, 해당 결함은 재현 테스트를 먼저 쓴 뒤 고쳤다.

- 문제 정의: 소비자원 원문 p8 권고("계약서에 이사화물 내역·작업인원 수·추가서비스 내역 및 비용 등을 상세히 기재")를 실제로 할 수 있게 하는 도구
- 기존 코드 재사용: 성남 KAIST(스택·구조화 호출), MoveValue(판정은 코드·문장 틀), 맛대패스(금지 표현 가드), TTA(검증 루프·예시 모드) — 상세 [[이사-지킴이-웹-설계]]
- 검증: 단위 테스트 15/15, `tsc` 통과, `next build` 성공, 헤드리스 390×844 예시 흐름 오류 0, 잘못된 요청 400, 내 사진+예시 모드 경고 표시 확인
