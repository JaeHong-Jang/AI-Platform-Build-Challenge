### 1. 집문서 안심 — 임대차 계약서·등기부등본을 올리면 위험 신호와 근거를 짚어주는 청년 전월세 점검 코파일럿
- **주요 사용자**: 관악구 신림·봉천·대학동 일대의 자취 대학생·사회초년생(첫 계약자).
- **문제**: 관악구는 청년층 45.2%, 1인가구 57.3%로 서울 1위(위 공통 사실). 보증금 미반환 피해 중 2030이 67.6%(1,459건/2,160건, HUG 자료 2021-08 기준 보도): https://newstomato.com/ReadNews.aspx?no=1090169 . 관악구·오산 깡통전세 빌라 100여 채, 세입자 49명 약 100억 원 보증금 미반환 혐의 수사 보도: https://www.kyeonggi.com/article/20230523580064 (최신 구별 피해 통계는 unknown).
- **왜 AI여야 하나**: 등기부등본(갑구·을구)과 특약 조항은 비정형 PDF/사진이다. 규칙 기반 계산기는 숫자 입력만 받고 "근저당 채권최고액+보증금" 같은 표 추출과 특약의 위험 문장 판독을 못 한다.
- **AI 적용 방식**: VLM/OCR로 등기부·계약서 필드 추출 → 실거래가 API로 시세 추정 → 규칙(선순위채권+보증금 / 주택가액 비율 등) 계산 → LLM이 위험 항목을 근거 조문·수치와 함께 설명(RAG: 주택임대차보호법·HUG 보증 기준). 파이프라인: 업로드 → 추출 → 도구호출(시세) → 규칙 점수 → 설명 생성.
- **데이터/API**: 국토부 아파트 전월세 실거래가 API https://www.data.go.kr/data/15126474/openapi.do (무료, 제한 없음, 신청 후 키). 연립다세대·오피스텔·단독다가구 전월세 API도 같은 체계로 존재(검색에서 15126472/15126475 목록 확인, 각 이용조건은 unknown). 법령은 국가법령정보센터(이용조건 unknown, 신청 전 확인). 데모용 등기부는 가상 샘플(실제 개인 등기부 사용 금지).
- **핵심 기능 3개 & 흐름**: (1) 문서 업로드 시 필드 자동추출 (2) 동일 법정동 최근 전월세 대비 보증금 위치 + 위험 점수 (3) 특약 문장 하이라이트와 "중개사에게 물을 질문" 체크리스트. 흐름: 주소·계약서 올리기 → 위험 요약 카드 → 질문 리스트 저장.
- **하루 해커톤 MVP 범위**: 가상 계약서 3종과 가상 등기부 2종, 아파트·다세대 중 한 유형의 실거래가 호출 1개 법정동(관악구 신림동 코드), 점수 규칙 5개, 설명 UI. 법률 자문이 아닌 "확인 포인트 안내"로 한정.
- **경쟁·유사 서비스와 차별점**: HUG 안심전세앱(가입 가능 여부 조회는 공식 설명 미확인, 블로그 기준), 세이프홈즈(앱스토어 등록 확인, 기능 세부 unknown). 차별점: 특약 문장 단위 설명과 근거 인용, 대학가 자취 청년 UX. 추정: 기존 서비스는 주소 기반 조회 중심.
- **관련 논문/근거**: CUAD: An Expert-Annotated NLP Dataset for Legal Contract Review (2021) arXiv:2103.06268 / OCR-free Document Understanding Transformer (Donut, 2021) arXiv:2111.15664 / Qwen2-VL (2024) arXiv:2409.12191.
- **리스크**: 법률 자문 오인(면책 문구 필수), 등기부 개인정보 포함 시 저장 금지, OCR 오류, 시세 API가 동·호 비공개라 정확도 한계.

### 2. 반지하 비상벨 — 비 오기 전 내 집 침수 위험을 계산하고 행동 지침을 알려주는 반지하·저층 거주자 에이전트
- **주요 사용자**: 관악구 반지하·옥탑·저층 거주 가구(청년, 고령자, 장애인 포함).
- **문제**: 관악구에 전체 반지하의 5.3%가 집중(최다, 위 SBS 출처). 2022-08 신림동 반지하에서 일가족 3명 사망: https://www.newsis.com/view/NISX20220812_0001977567 . 서울시는 차수시설 미설치 반지하 9,440가구를 파악(검색 요약, 원문 URL 확인 못 함 → 수치는 2차). 침수 피해 가구 수는 unknown.
- **왜 AI여야 하나**: 기상 경보는 "구 단위"이다. 개인의 층·위치·과거 침수 이력·대피 능력에 맞춘 행동 안내는 개인화와 자연어 대화가 필요하다.
- **AI 적용 방식**: 도구호출 에이전트(ReAct): 주소 → 침수흔적도 조회 → 강우 예보 → 개인 프로필 → 맞춤 대피 지침 생성. 파이프라인: 주소 입력 → GIS 질의 → 위험 등급 → LLM이 "지금 할 일" 3단계 + 보호자 알림 문구 생성.
- **데이터/API**: 서울 침수흔적도 shp(2010~2022 연도별)가 공공데이터포털·열린데이터광장에 있다는 보도: https://www.ytn.co.kr/_ln/0105_202407290534282671 (data.go.kr 목록 15134240/15134248/15134249가 검색에서 나왔으나 세부 내용 미확인). 기상청 단기예보 API(이용조건 unknown, 신청 시 확인). 서울 하수관로 수위·강우량 API는 존재 여부 unknown.
- **핵심 기능 3개 & 흐름**: (1) 주소별 침수 위험 등급과 과거 침수 여부 (2) 호우 예보 시 개인화 행동카드 (3) 보호자·이웃 자동 안내문 생성. 흐름: 주소 등록 → 예보 연동 → 알림/카드.
- **하루 해커톤 MVP 범위**: 관악구 일부 동의 침수흔적 shp를 GeoJSON으로 변환, 주소→좌표 변환, 위험 등급 규칙, 시나리오 시연("시간당 80mm 가정"). 실시간 알림 푸시는 제외.
- **경쟁·유사 서비스와 차별점**: 서울안전누리, 재난문자(내용은 확인 못 함). 차별점: 개인 주소·상태 기반 행동 안내.
- **관련 논문/근거**: ReAct (2022) arXiv:2210.03629 / Retrieval-Augmented Generation (2020) arXiv:2005.11401. 도메인 논문은 unknown.
- **리스크**: 침수흔적도 포괄 범위 한계(YTN 기사에서 지자체-중앙 지도 불일치 논의: https://www.ytn.co.kr/_ln/0105_202408012001432504), 오경보·안전 책임, 위치 정보 민감.
- **자체 점수(1~5)**: 문제심각도 5 / AI필연성 3 / 구현가능성 3 / 데이터확보 3 / 차별성 4 / 시연임팩트 4

### 3. 구·서울·중앙 통합 청년정책 판정기 — 내 조건으로 받을 수 있는 정책을 자격 판정하고 신청서 초안까지 만들어주는 RAG
- **주요 사용자**: 관악·금천 거주 청년, 청년 1인가구.
- **문제**: 서울 청년 주거 영역에서만 600개 이상의 정책이 흩어져 있다는 지적: https://www.venturesquare.net/1018366/ . 서울시 청년정책 플랫폼 '청년몽땅정보통'은 2023-12 AI 맞춤형으로 개편: https://news.seoul.go.kr/gov/archives/554506 . 서울 청년의 정책 인지도 수치는 unknown.
- **왜 AI여야 하나**: 공고문은 비정형 PDF/HTML이고 자격 조건(소득, 연령, 거주 기간, 중복 수혜 제한)이 문장으로 서술돼 있어 필터 UI로는 "내가 정말 받을 수 있는지"를 판정하기 어렵다.
- **AI 적용 방식**: 공고문 → 조건 구조화(LLM 추출) → 자격 판정(규칙+LLM) → 출처 문단 인용 답변(RAG). 파이프라인: 공고 수집 → 청킹/임베딩 → 사용자 프로필 → 후보 검색 → 조건별 충족/미충족/확인필요 표.
- **데이터/API**: 온통청년/청년몽땅정보통 공식 Open API 존재 여부와 신청 절차는 이번 검색으로 확인하지 못함(unknown). 대안: 공고 PDF 직접 수집(사이트 이용약관 확인 필요), 공공데이터포털에서 서울시 청년 관련 파일데이터 검색.
- **핵심 기능 3개 & 흐름**: (1) 자연어 프로필 입력 → 정책 매칭 (2) 조건별 충족/미충족 표와 원문 인용 (3) 신청서 체크리스트·준비서류 목록. 흐름: 대화로 조건 입력 → 매칭 리스트 → 자세히 보기.
- **하루 해커톤 MVP 범위**: 미리 수집한 정책 공고 30건을 벡터DB에 넣고, 프로필 6개 항목 기반 판정. 마감 임박 정렬. 실제 제출 대행은 제외.
- **경쟁·유사 서비스와 차별점**: 청년몽땅정보통(AI 맞춤), 온통청년, 씨지인사이드의 청년 주거정책 AI 챗봇(창업진흥원 대회 최우수상 보도, venturesquare 위 링크). 차별점: 구 단위(관악·금천)+캠퍼스타운 정보 포함, 조건별 "왜 안 되는지" 설명. 솔직히 기존 서비스와 겹침이 큰 아이디어이다.
- **관련 논문/근거**: RAG (2020) arXiv:2005.11401 / Self-RAG (2023) arXiv:2310.11511 / Lost in the Middle (2023) arXiv:2307.03172.
- **리스크**: 공고 최신성/오판정 책임, 크롤링 약관, 경쟁 서비스와 중복.
- **자체 점수(1~5)**: 문제심각도 4 / AI필연성 4 / 구현가능성 5 / 데이터확보 3 / 차별성 2 / 시연임팩트 3

### 4. 말 걸어주는 이웃 — 고립·은둔 위험 청년에게 부담 없는 대화와 동네 모임/공간을 연결하는 챗 동반자
- **주요 사용자**: 관악구 1인가구 청년 중 고립·은둔 경계에 있는 사람, 청년공간 운영자.
- **문제**: 서울 청년(19~39세) 4.5%(고립 3.3%, 은둔 1.2%), 약 12.9만 명 추정(서울시 2022 조사, 2023-01 발표): https://v.daum.net/v/20230118111513646 . 계기는 실직·취업난 45.5%, 심리적 어려움 40.9%, 인간관계 40.3%(검색 요약: https://www.dailian.co.kr/news/view/1295466/ ). 시 지원 규모가 500명이라는 제목의 기사도 있음(원문 미확인).
- **왜 AI여야 하나**: 은둔 청년은 전화·방문 상담을 꺼린다. 24시간 저부담 텍스트 대화로 첫 접점을 만들고, 사람(상담사)에게 연결하는 징검다리가 필요하다.
- **AI 적용 방식**: 안전 가드레일이 있는 대화형 LLM + 의도 분류(위기 키워드 감지 시 상담전화 연결) + 지역 모임·공간 추천(RAG). 파이프라인: 대화 → 위기 신호 분류 → 낮은 문턱 활동 제안 → 지역 자원 연결.

### 9. 쉬운 고지서 — 구청 공문·고지서 사진을 쉬운 한국어와 할 일 체크리스트(다국어 포함)로 바꿔주는 도우미

- **핵심 기능 3개 & 흐름**: (1) 주제별 건수 추이 (2) 대표 사례 요약 (3) 구별 비교.
- **하루 해커톤 MVP 범위**: 합성 민원 500건, 클러스터+요약 화면. 실제 데이터 부재가 약점이다.
- **경쟁·유사 서비스와 차별점**: 서울시 다산콜 AI 상담 지원/빅데이터 구축(서울시의회 예산 증액 보도: https://m.go.seoul.co.kr/news/2024/12/10/20241210500029 ). 이미 시가 투자 중이므로 차별화가 약하다.
- **관련 논문/근거**: From Local to Global: A Graph RAG Approach to Query-Focused Summarization (2024) arXiv:2404.16130 / M3-Embedding arXiv:2402.03216.
- **리스크**: 실데이터 접근 불가로 시연 신뢰도 낮음, 개인정보 포함 텍스트.
- **자체 점수(1~5)**: 문제심각도 3 / AI필연성 4 / 구현가능성 3 / 데이터확보 1 / 차별성 2 / 시연임팩트 2

## TOP 5 추천과 이유

1. **#1 집문서 안심**: 관악구의 청년 1인가구 집중(청년층 45.2%, 1인가구 57.3%)과 2030 중심 보증금 피해(67.6%)라는 지역 맥락이 가장 직접적이다. 실거래가 API가 무료·제한 없음으로 확인되어 데이터 확보가 쉽고, 문서 사진을 올리면 위험 근거가 표시되는 시연이 강하다. 법률 자문 오인 리스크는 면책과 "확인 포인트" 프레이밍으로 관리 가능하다.
2. **#5 말 통역 카드**: 금천구 외국인 비율 13.8%, 통역 없는 진료 미이해 24.5%, 의료통역은 예약제(3일 전, 연 4회)라는 구조적 공백이 서울시 보도자료로 확인되었다. STT+번역은 AI가 필연인 영역이고 라이브 시연 임팩트가 크다. 오번역의 의료 리스크는 증상 문답 카드와 되묻기로 완화한다.
3. **#2 반지하 비상벨**: 관악구는 반지하 최다(5.3%)이고 2022 신림동 사망 사고라는 사회적 설득력이 있다. 침수흔적도가 공개 데이터이며, 지자체가 도입하고 싶어 할 안전 서비스이다. 다만 침수 API·실시간 하수 수위 데이터 접근은 미확인이라 MVP는 정적 침수흔적+예보 시나리오로 한정해야 한다.
4. **#7 골목 신호등**: 서울시 상권분석 데이터가 공공누리 1유형으로 확인된 가장 안정적인 데이터 기반이다. 샤로수길 등 지역 상권 이슈와 연결되고 주최측(관악구, 캠퍼스타운)의 관심 영역이다. 단 상권 단위 데이터라 점포별 예측을 주장하면 안 된다.
5. **#3 통합 청년정책 판정기**: 구현가능성이 가장 높아 9시간 안에 완성도를 확보하기 쉽다. 그러나 청년몽땅정보통·민간 챗봇과 겹쳐 차별성이 낮다. 구 단위 정책과 "왜 안 되는지" 설명, 근거 인용으로 차별화할 수 있을 때만 선택하고, 아니면 #6(고령자 음성 안내)이 대안이다.

보류 의견: #13(안부 전화)은 문제는 심각하나 실데이터 확보가 불가능하고 개인정보 리스크가 커서 기획서에는 확장 아이디어로만 언급하길 권한다. #15는 실데이터 부재로 시연 신뢰도가 낮다.
