**분석 제안: 1순위는 임금 근거표, 2순위는 청년월세 증빙 점검, 3순위는 헬스장 해지 기록 정리다.** 지시어 연결 자막은 AI의 역할이 가장 뚜렷하지만, 하루 구현의 불확실성이 더 크다.

두 조사 파일과 이전 D001 판정을 모두 읽고 **11개 카드**로 재구성했다. 아래 순위는 실무팀 분석이며, peer·지휘부 검증 전이다.

공통 적용 기준은 다음과 같다.

- **벤치마크:** ✓는 공식 자료에서 해당 기능을 확인한 경우만 사용했다. 기능 미언급·기사만 확인·범위 불일치는 `?`로 정정했다. 명시적 부재 근거가 부족해 `✗`는 사용하지 않았다. `?`가 많다는 사실은 차별성이 입증됐다는 뜻이 아니다.
- **구현:** 모든 MVP 범위와 소요시간은 **추정**, 성공 지표의 목표값은 **제안**이며 아직 측정 결과가 없다.
- **데이터:** 직접 만든 가상 문서·촬영물로 시연한다. 외부 자료는 공식 페이지에서 수동 확인하고 출처·확인일·버전을 표시한다. 공개 열람과 재배포·모델 입력 허용은 구분하며, 이용 조건이 불명확하면 `unknown`으로 남긴다.
- **공통 기술 근거:** [Qwen2.5-VL Technical Report, arXiv:2502.13923](https://arxiv.org/abs/2502.13923)은 문서 구조 추출·객체 위치 지정·영상 시간별 위치 파악을 제시한다. 아래에서는 이를 **기술 근거 T**로 부른다. 개별 서비스의 한국어 정확도나 제품 효과를 입증하는 자료는 아니다.

### 7. 신청길 재검사 — 대학 웹 담당자의 접근성 경고를 수정 전후 과업 증거로 바꾼다

3. **왜 지금**

   | axe DevTools | ✓ | ? | ? | ? |

   목표 입력 → 키보드 경로 실행·기록 → 관련 기준과 담당자 확인 → 수정 후 동일 경로 재실행.

7. **하루 해커톤 MVP와 시연 장면**

8. **성공 지표**  
   제안: 삽입 문제 탐지 수, 정상 경로 오탐 수, 재실행 결과의 반복 일치율, 수정 전후 과업 완료 여부.

### 8. 작업 말 되짚기 — 이주노동자의 번역 수신을 장비·조건별 이해 확인으로 바꾼다
