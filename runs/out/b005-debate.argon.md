### **D1 · 당일 근거 카드의 P0 포함 여부**

1. **상대 주장에 대한 수용 (4줄)**
   - **수용한다.** 기술적으로는 P0의 추출·대조 데이터를 한 화면에 재조합하는 정적 뷰라 추가 백엔드 비용이 없으나, 이를 '당일 근거 카드'라는 별도 기능 명칭으로 P0에 두면 업체 답변 전인데도 합의 완료 문서처럼 오해받을 위험이 있고([법제처 표준약관 안내](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=3&cciNo=1&cnpClsNo=1&csmSeq=629)), '계약 직전 확인 도구'라는 핵심 메시지와 3분 시연 초점이 분산된다는 Astra의 지적에 동의한다.
   - 추정: 9시간 해커톤에서도 별도 카드 저장·공유 뷰를 만드는 것보다, P0 4단계(확인 요청 결과 화면) 한 곳에서 복사할 확인 문구와 연결된 방 사진·견적 원문 발췌(`rawTextQuote`)·참고 조항을 함께 보여주는 편이 UI 구현 부담과 시연 실패율을 낮춘다.
   - 따라서 별도의 '이사 당일 대응 화면/카드 저장'은 P1로 이관하고, P0는 근거가 연결된 확인 요청 결과 화면으로 단일화한다.
2. **최종 입장**: **수정** (별도 '당일 근거 카드' 기능은 P1로 이관하고, P0의 4단계 확인 요청 결과 화면 안에서 복사 문구와 연결된 사진·견적 원문 발췌·참고 약관 조항을 함께 표시한다.)

### **D2 · 소비자원 통계의 "281건" 표기**

1. **상대 주장에 대한 수용 (5줄)**
   - **전면 수용한다.** 한국소비자원 공식 게시글([한국소비자원 보도자료 no=1004458186](https://www.kca.go.kr/home/sub.do?menukey=4005&mode=view&no=1004458186&page=1)) 웹 본문을 확인한 결과, 소규모 이사 분석 대상 **241건**(신청자 중 20~30대 **65.1%·157건**)과 피해 유형별 **물품 파손·분실 134건(47.7%)**, **추가 비용 요구 70건(24.9%)**, **계약불이행 39건(13.9%)**, **과도한 위약금 27건(9.6%)**은 확인되나, **'281건'이라는 합계 수치는 웹 본문에 명시되어 있지 않다.**
   - '281건'은 비율 역산(`70 ÷ 0.249 ≈ 281.1`) 및 2차 보도([KBS/다음 뉴스](https://v.daum.net/v/20260421120242290))에서만 확인되며, 한국소비자원 게시글의 첨부 원표(HWP/PDF) 내 공식 표기 여부는 현재 열람 도구로 직접 확인할 수 없어 **`unknown`**이다.
   - 따라서 확인되지 않은 첨부표 수치를 본문에 확정 표기하는 것은 공통 규칙에 어긋나므로, '281건' 표기를 철회하고 본문(241건·65.1%)과 별도 표/문장(피해 유형별 집계에서 추가비용 요구 70건·24.9%, 241건을 분모로 한 비율이 아님)으로 분리하는 Astra 안을 따른다.
2. **최종 입장**: **철회** (수정안: 공식 첨부표 내 '281건' 표기 여부는 `unknown`이므로 기획서에서 '281건'을 삭제하고, 본문의 '분석 대상 241건(20~30대 65.1%)'과 별도 도표의 '피해 유형별 집계상 추가비용 요구 70건·24.9%(241건 분모 아님)'로만 분리 표기한다.)

### **D3 · P0 규칙 범위와 입력 개수**

1. **상대 주장에 대한 수용 및 기술 구체화 (5줄)**
   - **입력 개수(방 사진 1~3장, JPEG/PNG 견적 이미지 1장)와 단일 문서 간 증액 비교 제외를 수용한다.** 추정: 입력 상한을 방 사진 1~3장·견적 1장으로 줄이면 Vercel Serverless 요청 본문 한도(4.5MB, https://vercel.com/docs/functions/limitations) 초과 위험, 다중 사진 간 동일 가구 중복 합산 오류([arXiv:2402.03328](https://arxiv.org/abs/2402.03328)), 2장짜리 견적서 병합 로직, VLM 응답 지연을 동시에 줄여 9시간 내 구현 안정성이 크게 높아진다.
   - 또한 단일 견적 이미지만 받는 P0에서 '견적금액 대비 계약금액 증액 비교'는 실행 불가능하므로 제외하고, 표준약관 제4조 역시 고객 인적사항·보관이사 등 전체 항목을 검사하는 것이 아니므로 '필수항목 전체 검사 완료'나 '위법 판정'으로 출력하지 않는다([법제처 견적서 안내](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=3&cciNo=2&cnpClsNo=1&csmSeq=666)).
   - 다만 결정론적(Deterministic) 코드와 템플릿이 동작하려면 대조 대상이 명확해야 하므로, P0 규칙은 Astra가 제시한 3대 대조 축(**① 품목 포함 여부 미확인/모호, ② 작업조건·장비·차량·인원 기재 미확인, ③ 추가비 발생 조건 확인 질문 및 표준약관 제4조·제5조 제3항·제8조 제2·3항의 변경 사유·사전 고지 요건 참고 안내**, [법제처 표준약관 안내](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=3&cciNo=1&cnpClsNo=1&csmSeq=629))으로 고정한다.
2. **최종 입장**: **수정** (P0 입력은 방 사진 1~3장·견적 이미지 1장·작업조건으로 축소하고, P0 규칙은 두 문서 증액 비교와 위법 판정을 제외한 3개 확인 규칙[① 짐 품목 포함 여부, ② 작업조건·차량·인원·장비 기재 여부, ③ 추가비 발생 조건 확인 질문 및 제4·5·8조 단서 요건 참고 안내]으로 한정한다.)

### **의장 판정문 반영용 합의 가능안 (한 줄씩)**

- **D1 (당일 근거 카드)**: 별도의 당일 대응 화면·저장 기능은 P1로 이관하고, P0는 4단계 결과 화면에서 업체 확인 요청 문구 복사와 그 근거가 되는 방 사진·견적 원문 발췌·참고 약관 조항 표시를 한 화면에 함께 제공한다(업체 답변 전 합의 완료 표시 금지).
- **D2 (소비자원 통계 표기)**: 한국소비자원 첨부 원표의 '281건' 표기 여부는 직접 확인 전까지 `unknown`이므로 제출문에서 '281건'을 쓰지 않고, 본문에는 '소규모 이사 분석 대상 241건 중 20~30대 65.1%(157건)'를, 별도 표·문장에는 '소규모 이사 피해 유형별 집계 중 추가비용 요구 70건·24.9%(241건을 분모로 계산한 비율이 아님)'를 분리 배치한다([한국소비자원 보도자료](https://www.kca.go.kr/home/sub.do?menukey=4005&mode=view&no=1004458186&page=1)).
- **D3 (P0 규칙 범위와 입력 개수)**: P0 입력은 **방 사진 1~3장, JPEG/PNG 견적 이미지 1장, 출발·도착지 작업조건**으로 제한하며, 규칙 엔진은 단일 문서 간 증액 비교나 위법 판정 없이 **① 품목 포함 여부 미확인, ② 작업조건·차량·인원·장비 기재 미확인, ③ 추가비 발생 조건 확인 질문(표준약관 제4조·제5조 제3항·제8조 제2·3항은 변경 원인·사전 고지 요건을 포함한 참고 기준으로만 연결)**의 3가지 확인 항목만 출력한다([법제처 표준약관 안내](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=3&cciNo=1&cnpClsNo=1&csmSeq=629)).
