# B011 한글 양식 기획서

## 사용자 요구 (2026-10-24 22:20)
1. 사용자가 준 양식(`보고서/AI Platform Build Challenge 공모전 기획서.hwpx`, 첨부 1 — 공식 양식)에 한글 문서로 작성. 양식 지키기.
2. AI는 로컬 AI가 아니라 **Claude Sonnet 5.5**(배포 모델)로 서술.
3. 실제 문제 예시는 좋다 — 유지. 부정적 서술이 너무 많다 — 어필하는 어조로.
4. [표 11] 역할 분담 빼기. 본선 계획은 7번 자유 항목에 넣기(제안 → 반영).
5. 질문: AI 에이전트가 무엇을, 왜 해야 하는지 명확한가?

## 진행
- 집필: Astra(GPT 6) `runs/out/b011-write.astra.md` (1차는 프롬프트의 '셸 금지' 문구로 파일을 못 읽어 재실행) → Opus 다듬기 `보고서/build/proposal-hwp.md`(불리한 지표 두 줄을 '보수적 검증기 + 본선 개선'으로, 접두어 '추정/계획' 제거, 견적 최대 5건·시험 74개로 갱신).
- 조판: `보고서/build/make_hwpx.py`(양식 안내문 칸 7개를 본문으로 교체, 글자·문단·테두리 모양 추가, 표·그림·강조 상자) + 한글 COM으로 PDF 렌더링 확인(10쪽).
- 그림: 새 화면 캡처(장면·실행 흐름·결과·근거 장부) `보고서/build/img-hwp/`.
- 웹: 화면에 남은 옛 이름(문서 읽기관·채비팀 등)을 새 흐름 이름으로 교체.
- 상호 검증 Sonnet `runs/out/b011-review.sonnet.md`: 수치·출처·날짜 불일치 0, 표 11·인명 없음 확인. 지적 7건 반영(요약 수치에 측정 조건, '계획한다'→단정, 값 누락 1→9를 '보수적 검증' 한 줄로 공개, 일정 단서 정리, 과잉 단서 축약, DetectHiddenFees '판매자 소개 기준', TRITON 용어 설명, 답변 점검관 도구 호출 순서).
- 산출물: `보고서/이사지킴이_예선기획서.hwpx`(10쪽) + 확인용 `보고서/이사지킴이_예선기획서(한글양식).pdf`. 이전 HTML판 PDF는 그대로 둠. 팀명·구성원 칸은 사용자가 채움.
