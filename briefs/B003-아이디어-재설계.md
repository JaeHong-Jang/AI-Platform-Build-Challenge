# B003 문제 중심 아이디어 재설계 + 기존 서비스 벤치마킹

- **질문**: 누구의 어떤 문제를 겨냥하고, 왜 지금 해결해야 하며, 기존 서비스가 못 하는 것을 AI로 어떻게 해결하는가? 이 기준으로 아이디어를 다시 세우고 10~15개를 추천하라.
- **범위**: (1) 문제 인벤토리(문제→대상→심각도 근거→기존 해결책→빈 곳) (2) 기존 서비스 벤치마킹(국내·해외, 기능 비교표) (3) 문제 중심 아이디어 카드
- **성공 기준**: 아이디어마다 경쟁 서비스 3개 이상을 공식 페이지로 확인한 비교표가 있고, "기존 서비스엔 없다"는 주장은 모두 상호 검증을 통과할 것
- **유지 후보**: D001 상위 8개(L03·L08·L09·L01·L04·L13·L05·L06)는 벤치마킹 후 살리거나 버린다
- **마감**: 2026-10-24 오전 (기획서 작성 시간 확보)
