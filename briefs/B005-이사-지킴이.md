# B005 이사 추가요금 분쟁 방지 서비스 심층 설계

- **출발점**: 사용자가 B004 피치 중 직접 선택 — "사진 보냈는데 이 선반은 별도래요" (소규모 이사 피해 중 추가비용 요구 24.9%, 피해 신청자 65.1%가 20~30대)
- **질문**: 이사 당일 "이건 추가요"를 AI로 어떻게 막는가? 기존 이사 플랫폼·AI 견적 서비스와 무엇이 확실히 다른가?
- **범위**: 문제 근거·규정(이사화물 표준약관) / 국내외 경쟁 벤치마킹 / 서비스 설계(견적 전→당일→입주 후, 흠집 보증금 아이디어 결합 검토) / 하루 MVP
- **팀 조건**: 웹·앱 개발 강점, AI는 API 활용
- **성공 기준**: 경쟁 서비스 대비 차별점이 공식 자료로 검증되고, 3분 시연 시나리오와 하루 구현 범위가 확정될 것
