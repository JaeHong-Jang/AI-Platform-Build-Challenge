# B007 이사 지킴이 대시보드 재설계 (Ollama 에이전트)

- **출발점**: 사용자 — "대시보드 형태로 만들어야 돼. 이렇게 만들면 안 되고, AI Agent는 Ollama로 해 일단. 문제를 정확하게 해결할 수 있게. 다른 폴더들을 팀 구조로 다 찾아서 웹사이트를 어떻게 구체적으로 만들었는지 봐. 색상도 어떤 걸 쓸지 정확하게 보고하라"
- **반성**: B006 조사는 LLM 호출 코드만 봤고 사용자 기존 사이트의 화면·디자인 체계는 보지 않았다. 모바일 단계형(wizard)으로 만든 것은 사용자 의도(대시보드)와 다르다.
- **조사**: Sonnet A — 기존 7개 프로젝트의 디자인 체계(색상 hex·역할, 글꼴, 레이아웃, 대시보드 컴포넌트) / Sonnet B — 기존 Ollama 코드 + 로컬 Ollama 도구 호출 실측 / Opus — 기존 사이트 실제 화면 캡처
- **분석**: Sol — 문제를 정확히 해결하는 대시보드 정보 구조(무엇을 한눈에, 어떤 순서로)
- **보고 후 구현**: 색상·레이아웃 명세를 사용자에게 먼저 보고
- **제약**: Ollama 모델은 텍스트 전용(qwen2.5:7b, qwen3:4b, ax4-light, gemma2:9b) — 이미지 읽기 방식은 별도 결정 필요
