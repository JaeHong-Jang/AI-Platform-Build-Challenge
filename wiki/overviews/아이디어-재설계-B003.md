# 문제 중심 아이디어 재설계 (B003 판정)

과정: 조사([[Sol]] 문제 인벤토리 12 ∥ [[Sonnet]] 기존 후보 8개 벤치마킹) → 분석(Sol·Sonnet 각자 카드 11개) → 상호 검증(Sol↔Sonnet, 공식 페이지 재확인) → 지휘부 검증([[Astra]] 전략 ∥ [[Argon]] 기술, 블라인드) → 토론(갈린 2건 + 결합안) → 판정([[Opus]]). 이전 판정은 [[아이디어-최종추천]](D001).

## 핵심 발견 — 모든 상위 후보에 같은 구조가 있다
헬스장 환불·임금·청년월세·상가 퇴거 어느 분야든 **계산기·안내·신청서 생성은 이미 있다.** 추정: 상대적으로 덜 다뤄진 곳은 그 **앞 단계**, 즉 **여러 원문(계약서 사진·영수증·출석 기록·카톡)에서 날짜·사실을 뽑아 서로 맞지 않는 곳을 찾고 원문과 연결하는 일**이다. 확인한 헬스장 계산기 6곳의 화면은 모두 사용자가 값을 직접 옮겨 적는 방식이었다. 같은 기능을 하는 서비스가 없다는 것은 **unknown**이다.

## 1위 · 헬스장 중도해지 증거 사건표

- **왜 해결해야 하나**: 한국소비자원 헬스장 피해구제 신청 **10,746건(2021~2024.3분기)**, 소비자원이 **해지 의사표시 입증자료 확보**를 직접 당부. [소비자원](https://www.kca.go.kr/home/sub.do?menukey=4005&mode=view&no=1003802911&page=3) — 관악구 1인가구 비율 63.5%([스마트관악](https://smart.gwanak.go.kr/gwanakatglance.do), 2025-09, 청년만의 비율 아님)·대학가 생활 분쟁과 연결된다(추정).

- **해결 흐름**: 자료 올리기(계약서 사진·영수증·출석 캡처·대화) → **AI**가 날짜와 사건을 추출하고 **사건 유형부터 구분**(해지 의사 발화일 · 해지 희망일 · 센터 도달·접수일 · 마지막 이용일 — 유형이 다른 날짜는 충돌이 아님) → **규칙**이 같은 유형끼리 출처 간 불일치 검출, 모호한 의사표현은 '확인 필요'로 남김 → **사람**이 기준일 확정 → 원문 번호가 붙은 상담용 사건표 1장
- **환급 계산은 조건부**: 소비자분쟁해결기준 별표 2(체육시설업) **최신 원문 대조가 아직 안 됨**(Sol: 본문 추출 실패, 결정례로 기간제 산식만 확인). 별도 규칙 검증을 통과하기 전에는 MVP 확정 범위에서 **제외**하고, 넣더라도 '합의·권고 기준에 따른 참고 범위'로만 표시
- **하루 MVP / 3분 시연**: 기간제 헬스장 계약 1건(PT·휴회·양도 제외). "10월 5일 '이번 달까지만 다닐게요'(카톡, 해지 의사 발화) vs 10월 18일 센터 해지 접수(도달·접수)"를 서로 다른 유형으로 나란히 원문과 표시 → 사용자가 기준일 선택 → 사건표 출력 (환급 범위 비교는 규칙 검증 통과 시에만)
- **성공 지표**: 사건 15개 날짜·유형 추출 정확도, 해지 요청 원문 찾기 성공률, 심어 둔 충돌 3건 탐지율, **정상 사례 오탐 수·보류율**, 수동 정리 대비 시간. 평가는 개발에 쓰지 않은 **별도 작성자의 정상·오류·예외 사례**로 한다
- **위험**: 환급액을 확정 채권처럼 표시 금지(소비자분쟁해결기준은 합의·권고 기준) · 상대방 대화 개인정보 → 가상 자료 · "경쟁 없음" 주장 금지

## 2위 · 강의 지시어–화면 연결 (도전 트랙)
- **문제**: 청각장애·난청 대학생이 자막은 읽어도 "여기서 이 항을 옮기면"이 화면의 어느 식·그래프인지 놓친다. (빈도·학업 손실은 unknown — 당사자 검증 필요)
- **벤치마크**: Tkita·Ava·Google Slides 자막(음성→자막 ✓) · Otter(슬라이드 자동 캡처 ✓) · Genio Notes(슬라이드·필기 동기화) — **지시어가 가리키는 세부 영역 연결은 공식 자료에서 확인되지 않음(?)**. [Otter](https://help.otter.ai/hc/en-us/articles/5093321813911-Automated-Slide-Capture-Overview) · [Tkita](https://www.tkita.ai/ko/product/caption)
- **차별점**: "기존 도구는 자막과 슬라이드 캡처까지, 우리는 '이 식·여기'가 가리키는 **영역 후보를 강조하고, 모호하면 '대상 불명'으로 남기고 학생이 고치게** 한다."
- **하루 MVP**: 자체 제작 2분 강의 · 지시어 10개 · 비실시간 처리 · 미리 나눈 수식 블록. 실시간 음성·포인터 추적은 제외 (Argon: 하루 안에 반드시 실패). **지시어→영역 연결은 실제 AI가 해야 하며, 정답 연결을 미리 입력한 시연은 금지**. 지표: 정답 연결률·오연결·보류율

## 3위 · 알바 임금 근거표 (1위 엔진의 확장)

- **살릴 조건**: 진정24에 같은 합성 입력을 넣어 비교한 뒤, **근무표·대화·명세서의 같은 날짜 충돌을 원문과 나란히 보여 주는 검토 화면**에 추가 가치가 있으면 승격.
