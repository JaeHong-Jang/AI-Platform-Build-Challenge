# 작업 파이프라인
과제 지시([[Opus]]) → 조사([[Sol]] ∥ [[Sonnet]]) → 분석([[Sol]] ∥ [[Sonnet]]) → 상호 검증(Sol ↔ Sonnet) → 지휘부 검증([[Astra]] ∥ [[Argon]]) → 토론(갈리는 주장만) → 판정([[Opus]], decisions/) → 위키 반영 → 저장소 반영 → 다음 과제 지시

규칙: 자기 산출물 승인 금지, 조사·분석은 병렬 독립, 토론은 판정이 갈리는 주장에만. 상위: [[팀-구조]]
