# 과제 B003 · 지휘부 검증 (당신: astra, 지휘부) — 블라인드 독립 리뷰
다른 지휘부 멤버의 리뷰는 보지 않는다. 아래 네 파일을 직접 열어 모두 읽어라.
- `runs/out/b003-analysis.sol.md` — Sol의 아이디어 카드 11개
- `runs/out/b003-analysis.sonnet.md` — Sonnet의 아이디어 카드 11개
- `runs/out/b003-peer-on-sonnet.sol.md` — Sol이 Sonnet 분석을 검증한 결과
- `runs/out/b003-peer-on-sol.sonnet.md` — Sonnet이 Sol 분석을 검증한 결과

당신의 관점 — 전략·사업성·심사 관점: 이 대회 심사위원(서울시·관악구·금천청년꿈터·서울대 캠퍼스타운·데이콘 추정)이 '문제가 진짜고, 기존 서비스와 명확히 다르며, 이 팀이 해낼 수 있다'고 느끼는가. 경쟁 서비스(특히 정부·대기업)가 같은 기능을 곧 낼 위험.

할 일:
1. 두 분석에 나온 아이디어를 같은 것끼리 묶어 **후보 목록**을 만든다 (대략 10~12개).
2. 후보마다: **찬성 / 반대 / 보류** + 이유 2~3줄 + 점수(문제 심각도, AI 필연성, 차별성, 하루 구현성, 심사 매력 — 각 1~5).
3. 상호 검증에서 '반박'되거나 '차별점 수정 필요'가 나온 주장은 수정안을 반영해 평가하라. 검증이 틀렸다고 보면 근거를 대라 (필요하면 웹 검색).
4. 최종 추천 TOP 5와 각각의 **차별점 한 문장**("기존 A는 ○○까지, 우리는 ●●")과 **시연 3분 장면**.
5. 마지막에 "다른 지휘부 멤버와 의견이 갈릴 것 같은 주장" 2~3개 (토론 단계에서 쓴다).
