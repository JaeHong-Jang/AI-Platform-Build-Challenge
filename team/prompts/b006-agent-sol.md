# 과제 B006 · 분석 (당신: sol, 실무팀) — AI 에이전트 배치와 문제 정의
먼저 읽어라: `decisions/D003-이사-지킴이-제작계획.md`, `wiki/overviews/이사-지킴이-제작계획.md`, `wiki/sources/kca2026-소규모이사-피해.md`.

사용자 요청: "어디를 AI Agent를 어떻게 사용해서 사용자에게 줄지, 왜 어떤 문제를 명확하게 잡았고 어떤 문제를 해결할지" 를 분명히 해 달라. 웹(모바일 웹)으로 만든다는 것은 확정.

할 일:
1. **문제 정의 한 문장**과 그 아래 3줄: 누가(사용자) / 언제(순간) / 무엇 때문에(원인 — 비대면 견적에서 짐·작업조건이 문서에 안 적힘) / 어떤 손해(당일 추가요금·이사 거부). 우리가 **해결하는 것 / 해결하지 않는 것**을 표로. 근거는 소비자원 원문 수치만 쓰고 쪽 번호를 달아라.
2. **AI 에이전트 배치표**: 사용자 흐름의 단계마다 (a) 거기서 쓰는 것이 단순 LLM 호출인지, 도구를 고르고 반복하는 에이전트인지, 규칙 코드인지 (b) 왜 그것이어야 하는지 (c) 실패하면 어떻게 되는지 (d) 사용자가 받는 화면 결과. D003의 원칙(판정은 규칙, 없는 조항 금지)을 깨지 않으면서 **에이전트가 진짜 가치를 내는 자리**를 찾아라. 후보 예: 부족한 정보만 골라 사용자에게 되묻는 '빠진 정보 질문 에이전트', 견적서 원문에서 근거 문장을 찾아 카드에 붙이는 단계, 업체 답변을 읽고 미확인 항목을 갱신하는 단계(P1). '에이전트'라는 말을 장식으로 쓰는 자리는 솔직하게 "에이전트 불필요"라고 판정하라.
3. 에이전트를 쓰는 자리마다 **도구 목록(이름·입력·출력 JSON)**과 최대 반복 횟수·종료 조건·사람 확인 지점.
4. 심사위원이 "이게 왜 AI 에이전트 서비스냐"고 물을 때의 답 3줄.
5. 확인하지 못한 것은 unknown.
결과는 마크다운 한 문서로.
