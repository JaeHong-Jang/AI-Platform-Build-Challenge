# 과제 (당신: GPT 6.1 Sol, 조사팀 — 근거 수집)
아이디어를 내지 말고, 아이디어 선정의 **근거 자료집**을 만들어라. 웹 검색으로 확인한 사실만, 모두 출처 URL 포함.
1. **문제 지형 통계 (한국, 2024~2026 최신)**: 청년(고립·은둔, 취업, 주거, 정신건강), 고령자(디지털 소외, 고독사), 장애인(정보 접근성), 이주민·외국인, 소상공인(폐업률, 행정부담), 1인가구, 안전(전세사기, 보이스피싱, 재난), 교육 격차, 의료 접근성 등 — 영역별 핵심 수치 2~3개.
2. **서울시 관악구·금천구 특화 이슈**: 청년·1인가구 비율, 지역 정책 사업, 금천청년꿈터·서울대 캠퍼스타운(앵커사업단)의 관심사.
3. **활용 가능한 공개 데이터/API 카탈로그** 20개 이상: 공공데이터포털(data.go.kr), 서울 열린데이터광장, AI-Hub, 법령/판례 API, 복지로·온통청년 등 정책 데이터, 지도/교통 API 등 — 이름, URL, 접근 방법(키 발급 필요 여부), 이용 조건, 해커톤에서 쓸 만한 이유.
4. **유사 대회 수상작 패턴**: 최근 DACON/서울시/공공 AI 서비스 해커톤·공모전 수상작 5개 이상과 공통적으로 높게 평가된 요소.
5. **이미 포화된(피해야 할) 아이디어 유형**과 그 근거.
